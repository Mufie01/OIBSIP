
# Retail Sales Data Analysis

## Internship
Oasis Infobyte – Data Analytics Internship

## Task
Level 1 – Task 1: Exploratory Data Analysis on Retail Sales Data

## Project Overview
This project analyses retail sales data to understand
customer purchasing behaviour, product category
performance and sales trends.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed
1. Dataset inspection and cleaning
2. Statistical analysis
3. Customer age and gender analysis
4. Product category revenue analysis
5. Monthly and quarterly sales analysis
6. Correlation heatmap
7. Business insights and recommendations

## Dataset Source
https://www.kaggle.com/datasets/mohammadtalib786/retail-sales-dataset

## Project Files
- eda_retail_sales.ipynb – Complete analysis notebook
- charts/ – Visualisations generated during analysis

## Conclusion
This project demonstrates the use of exploratory
data analysis to identify patterns and generate
meaningful insights from retail sales data.
